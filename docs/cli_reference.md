# Kronos CLI Reference

Kronos is completely controllable via the `kronos` command line interface. This document outlines every available command and subcommand.

## Core & Setup
*   `kronos setup` - Run interactive local setup (legacy — prefer onboard).
*   `kronos onboard` - The full first-run wizard. Configures your LLM provider, core skills, Telegram pairing, and MCP presets.
*   `kronos doctor [--ping]` - Show local setup and security status. The `--ping` flag runs a live API call to verify your configured provider credentials.
*   `kronos models` - List all supported AI providers and their respective models.
*   `kronos web` - Launch the local Kronos Next.js web dashboard manually.

## Daemons & Execution
*   `kronos` - Start the default interactive CLI agent session.
*   `kronos start` - Start the Kronos daemon in the background.
*   `kronos stop` - Stop the background Kronos daemon.
*   `kronos daemon` - Run the V3 Watchdog Supervisor in the foreground.

## Integrations (Telegram & Discord)
*   `kronos telegram run` - Run the Telegram bot worker. (Usually handled by Docker Compose).
*   `kronos telegram pair` - Generate a Telegram pairing code to securely link your Telegram account to your local agent.
*   `kronos discord run` - Run the Discord bot worker.

## Skills Management
*   `kronos skills list` - List all installed skills and available catalog skills.
*   `kronos skills search <query>` - Search the online skill catalog.
*   `kronos skills install <name or url>` - Install a skill from the catalog or directly from a URL.
*   `kronos skills reload` - Force the engine to reload all skills from disk.

## MCP (Model Context Protocol)
*   `kronos mcp list` - List all configured MCP servers.
*   `kronos mcp add <name> [--preset] [--exec] [--args]` - Add a new MCP server. You can use `--preset` for built-ins (like `filesystem`, `fetch`, `github`), or specify an executable.
*   `kronos mcp enable <name>` - Enable an existing MCP server.
*   `kronos mcp disable <name>` - Disable an MCP server without deleting it.
*   `kronos mcp test <name>` - Test connectivity and handshake with an MCP server.
*   `kronos mcp tools [--server]` - List all tools exposed by connected MCP servers.

## Self-Improvement & Proposals
*   `kronos proposals list` - List all pending self-improvement code or logic proposals generated by the agent.
*   `kronos proposals approve <id>` - Approve a proposal (by its ID prefix) and allow Kronos to apply it.
*   `kronos proposals reject <id>` - Reject a proposal.

## Maintenance & Data
*   `kronos export-trajectories [--format] [--output] [--success-only] [--since] [--until] [--max]` - Export the agent's interaction trajectories for fine-tuning. Supports SFT, GRPO, and CSV formats.
*   `kronos usage` - View your historical API usage and estimated token costs.
*   `kronos backup export [--output]` - Export your entire local database (Epistemic Graph, memories, settings) to a zip file.
*   `kronos migrate scan --from <hermes|openclaw> [--path]` - Scan your machine for migratable data from Hermes or OpenClaw agents.
*   `kronos migrate import --from <hermes|openclaw> [--path] [--dry-run | --apply]` - Safely import state and memories from legacy agents.
