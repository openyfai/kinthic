# Kinthic CLI Reference

Kinthic is completely controllable via the `kinthic` command line interface. This document outlines every available command and subcommand.

## Core & Setup
*   `kinthic setup` - Run interactive local setup (legacy — prefer onboard).
*   `kinthic onboard` - The full first-run wizard. Configures your LLM provider, core skills, Telegram pairing, and MCP presets.
*   `kinthic doctor [--ping]` - Show local setup and security status. The `--ping` flag runs a live API call to verify your configured provider credentials.
*   `kinthic models` - List all supported AI providers and their respective models.
*   `kinthic web` - Launch the local Kinthic Next.js web dashboard manually.

## Daemons & Execution
*   `kinthic` - Start the default interactive CLI agent session.
*   `kinthic start` - Start the Kinthic daemon in the background.
*   `kinthic stop` - Stop the background Kinthic daemon.
*   `kinthic daemon` - Run the V3 Watchdog Supervisor in the foreground.

## Integrations (Telegram & Discord)
*   `kinthic telegram run` - Run the Telegram bot worker. (Usually handled by Docker Compose).
*   `kinthic telegram pair` - Generate a Telegram pairing code to securely link your Telegram account to your local agent.
*   `kinthic discord run` - Run the Discord bot worker.

## Skills Management
*   `kinthic skills list` - List all installed skills and available catalog skills.
*   `kinthic skills search <query>` - Search the online skill catalog.
*   `kinthic skills install <name or url>` - Install a skill from the catalog or directly from a URL.
*   `kinthic skills reload` - Force the engine to reload all skills from disk.

## MCP (Model Context Protocol)
*   `kinthic mcp list` - List all configured MCP servers.
*   `kinthic mcp add <name> [--preset] [--exec] [--args]` - Add a new MCP server. You can use `--preset` for built-ins (like `filesystem`, `fetch`, `github`), or specify an executable.
*   `kinthic mcp enable <name>` - Enable an existing MCP server.
*   `kinthic mcp disable <name>` - Disable an MCP server without deleting it.
*   `kinthic mcp test <name>` - Test connectivity and handshake with an MCP server.
*   `kinthic mcp tools [--server]` - List all tools exposed by connected MCP servers.

## Self-Improvement & Proposals
*   `kinthic proposals list` - List all pending self-improvement code or logic proposals generated by the agent.
*   `kinthic proposals approve <id>` - Approve a proposal (by its ID prefix) and allow Kinthic to apply it.
*   `kinthic proposals reject <id>` - Reject a proposal.

## Maintenance & Data
*   `kinthic export-trajectories [--format] [--output] [--success-only] [--since] [--until] [--max]` - Export the agent's interaction trajectories for fine-tuning. Supports SFT, GRPO, and CSV formats.
*   `kinthic usage` - View your historical API usage and estimated token costs.
*   `kinthic backup export [--output]` - Export your entire local database (Epistemic Graph, memories, settings) to a zip file.
*   `kinthic migrate scan --from <hermes|openclaw> [--path]` - Scan your machine for migratable data from Hermes or OpenClaw agents.
*   `kinthic migrate import --from <hermes|openclaw> [--path] [--dry-run | --apply]` - Safely import state and memories from legacy agents.
