FAQ

Straight answers.

Does it phone home?

No. Gateway binds to 127.0.0.1. Data stays in ~/.kinthic/. Outbound calls are only to LLM providers you configure.

Can I migrate from OpenClaw or Hermes?

Yes. kinthic data migrate --from openclaw scans by default; add --apply to import. Same for Hermes.

Is the core free?

Yes — AGPL-3.0. Complete for one person on one machine. Commercial embedding requires a license.

Remote access?

ssh -N -L 8000:127.0.0.1:8000 user@server — never expose the gateway to the public internet without auth.
